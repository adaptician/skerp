# Enums

This solution uses SQLite with Entity Framework Core code-first migrations. The PostgreSQL-oriented
conventions in `.agents/standards/persistence.md` (schemas, snake_case table and column names,
`timestamptz`, native row versions) do not apply. 

Use standard EF Core conventions for the SQLite provider: PascalCase table and column names, no schema, and provider-default column types.
Every other rule in that standard still applies:
- explicit `IEntityTypeConfiguration<T>` classes
- explicit indexes and delete behaviour
- soft-delete query filters
- migrations generated by tooling
- UTC timestamps

Integration tests run against real SQLite (not the EF Core InMemory provider).
Where the SQLite provider cannot translate a type in a query (for example ordering or filtering on
`DateTimeOffset` or `decimal`), use a supported mapping and prove it in the first tracer bullet.

## Currency Enum

```csharp
enum CurrencyId
{
    Zar = 1,
    Usd = 2,
    Euro = 3,
}
```

## Status Enum
```csharp
/*
* Enum values are numbered explicitly to prevent mis-matches when new values are added.
* Values are spaced to accomodate later additions.
* Values do not need to be sequential, but it conveys intent of progression to other developers.
*
* If the solution is required to scale, the enum can be used to seed a table into the database,
* so that readable reporting queries can be drawn from data alone, without manually mapping enum values to display text.
*/
enum StatusId
{
    Pending = 10,
    Confirmed = 20,
    Fulfilled = 60,
    Cancelled = 90,
}
```

# Entities

## Guids

Entities with `Guid` PK should use `Guid.NewGuid();` be default unless explicitly directed otherwise.

## Dates

All dates are persisted in UTC in the database - conversion to local time must occur on the client-side.

## Computed Columns

DO NOT use computed columns unless explicitly asked for - the use of computed columns must always be approved by a human operator.

## Base Entity Class

ALL entities should inherit from a common base `MinimumAudit` unless explicitly marked an exception.

| Property | Data Type | Constraints |
|--|--|--|
| CreatedAt | datetime (required) | UTC Date and time of creation |
| LastModifiedAt | datetime | UTC Date and time of last modification |
| IsDeleted | boolean | soft-delete flag |
| DeletedAt | datetime | UTC Date and time of deletion |

Date and times should be stamped per transaction against the entity table where applicable.

# Deletes

All deletes are soft-deletes unless explicitly excluded.

Entities marked `IsDeleted = true` should always be filtered out of query results using a query filter.

Soft-deletes apply to cascades unless explicitly excluded.

## Purchase Order

Table Name: `PurchaseOrders`

A record is captured when a new purchase order is created.

| Property | Data Type | Constraints |
|--|--|--|
| Id | Guid (PK) |  |
| Reference | string (required) | UNIQUE external reference number; MIN LENGTH: 5, MAX LENGTH: 128 |
| CustomerId | Guid (FK) (required) | associated customer |
| CurrencyId | short (required) | Currency enum |
| CurrentStatusId | short (required) | current status id |
| Total | decimal (required) | Total; MIN VALUE: 0.01; PRECISION: 18,2 |

Indexes:
- UNIQUE index on Reference + IsDeleted
- index on CustomerId + IsDeleted

## Customer

Table Name: `Customers`

A record is captured when a new purchase order is created with a customer that does not yet exist.

| Property | Data Type | Constraints |
|--|--|--|
| Id | Guid (PK) |  |
| Name | string (required) | UNIQUE customer name; MIN LENGTH: 3, MAX LENGTH: 128 |
| Email | string (required) | valid email address; MIN LENGTH: 5, MAX LENGTH: 128 |

Indexes:
- UNIQUE index on Name + IsDeleted

## Status Changes

Table Name: `PurchaseOrderStatusChanges`

Exception: do NOT inherit from `MinimumAudit` base.

A record is captured whenever the status of a purchase order is changed.

| Property | Data Type | Constraints |
|--|--|--|
| Id | long (PK) |  |
| PurchaseOrderId | Guid (FK) (required) | associated purchase order |
| StatusId | int (required) | associated Status enum |
