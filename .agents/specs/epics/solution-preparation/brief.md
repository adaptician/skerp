# Solution Preparation

Prepare the solution for development by creating a new .NET solution under `src/` and an Angular app with Typescript under `client/`.

# Client Shell

The client should include 
- a background image 2560 x 1440 PNG that applies to all pages. This image will be provided - use a placeholder to begin.
- a navigation header that displays a branded emblem (use placeholder to begin) and wordmark, menu items, and a toggle for "Demo Mode".

# Landing screen

The default landing screen should display 3 stacked cards: a welcome message and summary of the application, a note for reviewers explaining how the developer notes toggle works, and a thank you message from the developer with a profile picture and links to LinkedIn and a professional site.
